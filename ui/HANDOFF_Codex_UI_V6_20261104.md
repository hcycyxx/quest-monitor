## UI 修改

- Windows 原生 DPI 绘制：界面继续使用 336 逻辑像素的布局，画布按实际屏幕比例绘制，避免系统放大低分辨率位图。
- 顶部按钮采用统一、安静的底色和轻微悬停反馈，去掉一排明显的黑方块。
- 暂停显示在顶部短标签中，保留最近行动内容，避免大块暂停提示压过任务信息。
- 收紧顶部层次，保留金色主线、冰青支线、蓝光及烟花。
- 每项任务的步骤均可展开和收起。修正窄条态恢复区域覆盖皮肤按钮的热区。

## 三项数据修复

1. UI 与引擎的读—改—写事务共用同一文件锁；临时文件每次唯一。不会再争用固定的 `quest_state.json.tmp`。
2. 手动操作记录在任务内部 `_user_state` 中，包括明确取消勾选的 false 值。引擎提交时重新读取最新状态，并应用用户操作，不再先合并过期请求快照。恢复整项任务时清空该项旧勾选和完成时间，避免刚恢复就显示全完成。
3. 完成历史不受“每类 8 项普通待办”的裁剪影响；模型省略的历史完成和手动编辑任务会被保留。发送给模型的完成历史摘要只取最近 6 项，完整历史仍留在本地。

若任务 JSON 格式损坏，修改事务报错而不是用空状态覆盖原文件。完成时间继续落盘。
