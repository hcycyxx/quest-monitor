## 四、验收中修掉的 3 个缺陷
1. **面板自我污染（`engine/win_watch.py`）**
   面板自己也是 `python.exe` 的 Tk 窗口，点它一下就被记成"当前活动"，AI 把 `任务追踪 · Codex V6` 当成用户在做的事，`current_activity` 变成面板标题。
   修：新增 `SELF_PREFIXES = ("任务追踪",)` + `is_self(w)`，`exe` 是 `python.exe`/`pythonw.exe` 且标题以「任务追踪」开头就跳过；主循环改 `if w and not is_self(w)`。
   同时清掉 `config/win_log.jsonl` 里 50 条历史污染记录（818 → 768 行）。修后 `grep -c 任务追踪` = 0。

2. **图钉图标忽隐忽现（`ui/quest_window.py:_header`）**
   原代码 `if name == "pin" and not self._dock_side: continue`，面板一旦被拖动（`_drag_start` 里 `_dock_side = None`）图钉就整颗消失，整排按钮位置跳动。
   修：始终绘制，未贴边时用 `mix(GLASS_BG,SUB,.55)` 压暗；提示语区分三态（未贴边 / 已贴边未固定 / 已固定）。

3. **标题点击极易误标完成（`ui/quest_window.py:_task`）**
   原热区 `_hit(cv,13,y,W-73,...)` 覆盖整行标题，且 ⓘ 图标只隔 8px。实测点击时把 WhatsApp 支线误标成完成。
   修：拆成两个语义明确的控件——
   - 左侧 12~36 固定圆点 = 完成/恢复开关（悬停显示「标记完成」/「恢复为进行中」）；
   - 标题区改为展开/收起步骤，不再改状态。
   实测点标题：状态从 `pending` 保持 `pending`，步骤正常展开。
   同时 ⓘ 图标右缘由 `W-32` 收到 `W-26`（list 画布宽只有 `W-24=312`，原位置被裁掉半个），标题宽度 `W-101` → `W-95`。
