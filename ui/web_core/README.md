# 当前界面代码

按 `ui/current_release.json` 的顺序连接这些文件，再包在同一个局部函数中执行。
保持既有运行语义，共享局部状态，不向全局暴露任务数据，也不需要新增打包工具。

- `00-runtime.js`：共享状态、请求等待/结果核对、设置和提示。
- `10-tasks.js`：任务卡片、完成反馈、主体视图及健康显示。
- `20-motion.js`：内容展开、窗口高度同步和滚动。
- `30-sort.js`：长按、拖动、占位及顺序保存。
- `40-window.js`：窗口操作、按钮和焦点。
- `50-timeline.js`：分页、增量数据和按ID保留的时间轴节点。
- `60-startup.js`：刷新和初始化。

`approved.css` 为已确认的界面基础样式；`style.css` 为当前桌面/卡片样式。
本次不改变视觉设计。历史文件仅保留供回退，当前代码不导入历史版本类。
